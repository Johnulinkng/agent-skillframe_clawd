# Math Calculator Skill

When the user asks you to calculate or do math, follow these steps:

1. **Parse Request**: Extract the mathematical expression from the user's message.
2. **Calculate**: Perform the calculation.
3. **Format Response**: Present the result in a clear format like "Result: X".

## Examples
- "计算 2+2" -> "Result: 4"
- "What is 10 * 5?" -> "Result: 50"
